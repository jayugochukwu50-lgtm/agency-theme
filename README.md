# Agency Theme

A custom, responsive WordPress theme for a fictional digital agency.
Built from scratch as a portfolio project, without a page builder or starter theme.

## Problem

Agency websites need a fast, maintainable theme that is easy to extend
and doesn't depend on heavy page builders.

## Features

- Reusable header and footer templates
- Stylesheet loaded properly with `wp_enqueue_style`
- BEM-structured CSS to avoid naming conflicts
- Escaped output for security

## Planned

- Navigation menu
- Home, Services and Contact page templates
- Responsive layout
- Contact form

## Technologies

PHP, WordPress, HTML5, CSS3 (BEM), vanilla JavaScript, Git

## Setup

1. Download or clone this repository
2. Zip the `agency-theme` folder
3. In WordPress, go to Appearance, Themes, Add Theme, Upload Theme
4. Upload the zip, install and activate
